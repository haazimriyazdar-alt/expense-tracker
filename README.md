# Expense Tracker

A command-line expense tracker built in Python.

## Features
- Add expenses with a name, category and amount
- View all expenses with the total and totals per category
- Data is saved to a JSON file so it is kept between runs

## How to run
1. Install Python 3
2. Run: python tracker.py

## What I learned
Functions, lists and dictionaries, loops, file handling with JSON, and basic input handling.
